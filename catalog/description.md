A Bluetooth remote for Claude Code.
Dictate with one button and run the session with the rest:
send the prompt, stop a turn, pick from a menu,
clear the conversation or change the effort,
whatever the computer's keyboard layout.

To the computer the Flipper is a keyboard, paired once,
that reconnects by itself within a second of a drop.
Each action confirms itself with a buzz,
so no buzz means nothing was sent.

## Buttons

- **OK, tap:** Enter, which sends the prompt or picks a menu's option
- **OK, hold:** Ctrl+Q, held until the release, which dictates into the prompt
- **Up and Down, tap:** the arrows, for message history and menus
- **Right, press:** Esc, which stops the turn
- **Up, hold:** Ctrl+X, Ctrl+F, which sets effort to high
- **Down, hold:** Ctrl+X, Ctrl+X, which sets effort to max
- **Left, hold:** Ctrl+X, Ctrl+L, which runs /clear
- **Back, hold:** nothing; it leaves the app

Dictation, effort and /clear take one block in Claude Code's keybindings.json.
The README covers
[pairing](https://github.com/petr-korobeinikov/f0-claude-remote#pairing)
and [the keybindings](https://github.com/petr-korobeinikov/f0-claude-remote#keys-on-the-mac).
